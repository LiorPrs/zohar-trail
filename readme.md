# 🥾 צועדים בשביל זוהר | לזכרו של זוהר תמיר ז"ל

אתר הנצחה קהילתי ואינטראקטיבי שהוקם ביוזמת החברים והמשפחה של זוהר תמיר ז"ל, במטרה להמשיך יחד את החלום שלו ולהשלים את כל **56 מקטעי שביל ישראל** — מקופות אתר החרמון בצפון ועד בית ספר שדה אילת בדרום.

🌐 **כתובת האתר:** <https://shvil-zohar.com>

---

## ✨ תכונות עיקריות וחוויית משתמש (Hybrid Responsive UX + Mini-CMS)

* **📱 ארכיטקטורה היברידית מותאמת פלטפורמה:**
  * **במובייל (`< 1024px`):** סרגל ניווט תחתון קבוע לאגודל (`🗺️ מפה` כברירת מחדל | `🥾 מקטעים` | `✉️ גלויות`), אזורי מגע מרווחים (`≥44px × 44px`), ופתיח מתקפל.
  * **במחשב (`1024px+`):** תצוגת **Split-Screen** מהודקת — רשימת המקטעים והגלויות מימין, והמפה האינטראקטיבית נעוצה (`Sticky`) משמאל.
* **🎨 ניהול גרפיקה וטקסטים ללא קוד (Self-Service Mini-CMS):**
  * מתוך תפריט הניהול באתר (`☰ -> עיצוב ותוכן האתר`), מנהלים יכולים להחליף באנרים, פורטרט, כרטיסיית 5 דקות וכותרות בלחיצת כפתור, עם אופטימיזציה אוטומטית לפני ההעלאה ל-Supabase Storage.
* **🗺️ מפת שביל ישראל אינטראקטיבית:**
  * מבוססת **Leaflet.js** ושכבת השבילים הטופוגרפית של **Israel Hiking Map** (עם מעבר למפת רחובות OpenStreetMap), גלולות סינון מהירות (`הכל`, `⚫ פנויים`, `🟠 משוריינים`, `🟢 בוצעו`) וסיכות ממוספרות (`1–56`).
* **🔔 התראות בזמן אמת לטלגרם:** חיבור אוטומטי דרך **Supabase Database Webhooks** ו-**Edge Functions** לקבוצת המנהלים בטלגרם בכל שריון חדש, העלאת תמונה לאישור או פנייה למנהלים.

## 📐 מפרט טכני מחייב לגרפיקה ותמונות (חובה להקפיד!)

בעת הכנת גרפיקה חדשה או החלפת תמונות דרך ממשק הניהול / הריפוזיטורי, יש להקפיד על המידות ויחסי הגובה-רוחב הבאים כדי למנוע חיתוך של פרטים חשובים:

| רכיב באתר | מזהה הגדרה (`key`) | מידות מומלצות | יחס גובה-רוחב | הנחיות עיצוב קריטיות |
| :--- | :--- | :--- | :--- | :--- |
| **באנר מחשב (`banner-desktop.jpg`)** | `banner_desktop_url` | **`1600 × 400 px`** | `4:1` (רחב) | **חשוב:** תמונת הפורטרט של זוהר חופפת את **הפינה הימנית התחתונה**. יש למקם את מוקד הציור/הנוף במרכז ובצד שמאל. |
| **באנר מובייל (`banner-mobile.jpg`)** | `banner_mobile_url` | **`900 × 450 px`** | `2:1` | מיועד למסכים צרים. יש להימנע מטקסטים קטנים בשוליים התחתונים. |
| **פורטרט זוהר (`zohar.jpg`)** | `zohar_portrait_url` | **`600 × 600 px`** | `1:1` (ריבוע) | מוצג כריבוע גדול עם פינות מעוגלות (`144px–176px`). הפנים צריכות להיות ממורכזות עם מרווח נשימה מסביב. |
| **כרטיסיית 5 דקות (`postcard-5min.jpg`)** | `postcard_5min_url` | **`1080 × 1350 px`** | `4:5` (אנכי) | מותאמת לצפייה והורדה כקובץ Offline לטלפון הנייד בזמן ההליכה בשטח. |
| **לוגו ואייקון שיתוף (`favicon.jpg`)** | קובץ בריפוזיטורי | **`512 × 512 px`** | `1:1` (ריבוע) | משמש כאייקון בראש האתר, בלשונית הדפדפן ובתצוגה המקדימה בוואטסאפ. |

> **הערה:** המערכת מבצעת אוטומטית דחיסה והמרה לפורמט `JPEG` איכותי בעת העלאה דרך ממשק הניהול כדי להבטיח טעינה מהירה גם בקליטה סלולרית חלשה בשטח.

## 🏗️ ארכיטקטורה וטכנולוגיות

| שכבה | טכנולוגיה | תפקיד |
| :--- | :--- | :--- |
| **Frontend** | HTML5, Vanilla JS, Tailwind CSS, Leaflet.js | ממשק היברידי רספונסיבי בקובץ יחיד (`index.html`) |
| **Backend & DB** | Supabase (PostgreSQL, Auth, Storage) | ניהול מקטעים, זיכרונות, הגדרות CMS ואחסון מדיה |
| **Serverless** | Supabase Edge Functions (Deno) + Webhooks | התראות אוטומטיות ל-Telegram Bot API |
| **Hosting & Domain** | Vercel + Namecheap (`shvil-zohar.com`) | פריסה אוטומטית ב-CDN עולמי ותעודת SSL |
| **Automation** | GitHub Actions (`keep-alive.yml`) | שמירה על פעילות רציפה של מסד הנתונים |

## 🗄️ הגדרת טבלאות ובאקטים ב-Supabase

1. **`segments`:** טבלת 56 מקטעי השביל (`id`, `title`, `region`, `distance`, `difficulty`, `lat`, `lng`, `official_url`).
2. **`memories` + `public_memories` (View):** אחסון שריונים, גלויות ופניות, כאשר `public_memories` מסתיר את מספרי הטלפון מהציבור.
3. **`site_settings`:** טבלת `key / value` לשמירת קישורי הגרפיקה והטקסטים הדינמיים (קריאה לציבור, כתיבה למנהלים מאומתים).
4. **Storage Buckets:**
   * `trail-photos` — תמונות שטח שמעלים המטיילים.
   * `site-assets` — קבצי הגרפיקה והבאנרים שמעלים המנהלים דרך ממשק ה-CMS.
