# 🥾 צועדים בשביל זוהר | לזכרו של זוהר תמיר ז"ל

אתר הנצחה קהילתי ואינטראקטיבי שהוקם ביוזמת החברים והמשפחה של זוהר תמיר ז"ל, במטרה להמשיך יחד את החלום שלו ולהשלים את כל **56 מקטעי שביל ישראל** — מקופות אתר החרמון בצפון ועד בית ספר שדה אילת בדרום.

🌐 **כתובת האתר:** <https://shvil-zohar.com> (ודמו ב-Vercel: <https://zohar-trail.vercel.app/>)

---

## ✨ תכונות עיקריות וחוויית משתמש (Mobile-First UX)

* **📱 ממשק Mobile-First מותאם לאגודל (Thumb-Friendly):**
  * **ניווט תחתון קבוע (`Sticky Bottom Tab Bar`):** מעבר מהיר בין **🗺️ מפה** (תצוגת ברירת המחדל מיד עם הכניסה), **🥾 מקטעים (56)** ו-**✉️ גלויות**.
  * **אזורי מגע מרווחים (`≥44px × 44px`):** כל הכפתורים, גלולות הסינון, פקדי המפה וכפתורי השמירה במגירות התחתונות (`Bottom Sheets`) מותאמים ללחיצה נוחה ביד אחת וללא זום אוטומטי בטפסים (`16px`).
  * **פתיח ומד התקדמות מתקפלים:** כרטיס פתיחה תמציתי עם תמונת זוהר ופס התקדמות רב-שכבתי שנפתחים בלחיצה לסיפור המלא ולמפת 56 הקוביות.
* **🗺️ מפת שביל ישראל אינטראקטיבית (תצוגת ברירת המחדל):**
  * מבוססת **Leaflet.js** ושכבת השבילים הטופוגרפית של **Israel Hiking Map** (עם כפתור מעבר מהיר למפת רחובות ויישובים של OpenStreetMap).
  * **גלולות סינון מהירות על המפה** (`הכל`, `⚫ פנויים`, `🟠 משוריינים`, `🟢 בוצעו`) וכרטיס מידע צף בתחתית המפה.
  * **סיכות ממוספרות (`1–56`) לפי סטטוס:**
    * 🟢 **ירוק:** בוצע ואושר
    * 🟠 **כתום:** שוריין לתאריך עתידי
    * 🔴 **אדום מהבהב:** שוריין ועבר התאריך המשוער
    * ⚫ **שחור:** פנוי להליכה
* **📅 שריון מקטעים וריבוי קבוצות:** אפשרות לשריין תאריך עתידי, להוסיף הערת הצטרפות פומבית, לשתף הזמנה מוכנה בוואטסאפ ולהוריד את כרטיסיית השטח *"עצירה של 5 דקות"* לשימוש Offline. המערכת תומכת גם בחפיפות של מספר קבוצות על אותו מקטע.
* **📮 גלויות מהדרך & Lightbox:** העלאת תמונות מהשטח (עם דחיסה אוטומטית בדפדפן לרוחב `1200px`) ותשובות ל-3 שאלות העצירה, כולל תצוגת תמונות מוגדלת למסך מלא (`Lightbox`).
* **🔔 התראות בזמן אמת לטלגרם:** חיבור אוטומטי דרך **Supabase Database Webhooks** ו-**Edge Functions** לקבוצת המנהלים בטלגרם בכל שריון חדש, העלאת תמונה לאישור או פנייה למנהלים.
* **⚙️ ממשק ניהול מאובטח:** כניסת מנהלים דרך **Supabase Auth**, אישור/מחיקת גלויות, תיבת הודעות נכנסות עם קישור ישיר לוואטסאפ וייצוא גיבוי מלא לאקסל (`CSV`).

## 🏗️ ארכיטקטורה וטכנולוגיות

| שכבה | טכנולוגיה | תפקיד |
| :--- | :--- | :--- |
| **Frontend** | HTML5, Vanilla JS, Tailwind CSS, Leaflet.js | ממשק Mobile-First בקובץ יחיד (`index.html`) |
| **Backend & DB** | Supabase (PostgreSQL, Auth, Storage) | ניהול נתונים, אימות מנהלים, הרשאות RLS ואחסון תמונות |
| **Serverless** | Supabase Edge Functions (Deno) + Webhooks | שליחת התראות אוטומטיות ל-Telegram Bot API |
| **Hosting & Domain** | Vercel + Namecheap (`shvil-zohar.com`) | פריסה אוטומטית ב-CDN עולמי ותעודת SSL |
| **Automation** | GitHub Actions (`keep-alive.yml`) | שמירה על פעילות רציפה של מסד הנתונים ב-Supabase |

## 🔒 אבטחת מידע והרשאות (Supabase)

1. **אימות מנהלים (`Supabase Auth`):** גישה לממשק הניהול מתבצעת אך ורק באמצעות משתמשי אימייל וסיסמה המוגדרים ב-Supabase Authentication.
2. **הגנה על פרטיות המטיילים (`public_memories` View):** האתר הציבורי קורא נתונים מתוך `View` שמסתיר את עמודת `contact_info` (מספרי הטלפון) וחושף אך ורק הערות פומביות.
3. **מדיניות `Row Level Security (RLS)`:**
   * משתמשים אנונימיים (`anon`) רשאים להוסיף רשומות (`INSERT`) בלבד, כאשר דיווחי ביצוע (`completed`) והודעות (`message`) נכנסים אוטומטית עם `is_approved = false`.
   * פעולות קריאה מלאה (`SELECT` על `memories`), אישור (`UPDATE`) ומחיקה (`DELETE`) מותרות אך ורק למשתמשים מאומתים (`authenticated`).
4. **אחסון מדיה (`Storage: trail-photos`):** מוגבל לקבצי תמונה (`JPEG`, `PNG`, `WEBP`) עד `5MB`, ללא הרשאת מחיקה או דריסה לציבור.

## 🚀 עדכון ותחזוקה שוטפת

* **עדכון קוד האתר:** החלפת הקובץ `index.html` בריפוזיטורי מפעילה אוטומטית פריסה מחדש ב-Vercel תוך כ-15 שניות.
* **ניהול משתמשים:** הוספה או הסרה של מנהלים מתבצעת דרך פאנל **Supabase -> Authentication -> Users**.
* **תחזוקת מסד הנתונים:** קובץ `keep-alive.yml` מריץ שאילתת קריאה קלה אחת ליומיים כדי לשמור על פרויקט Supabase פעיל ברציפות.
